# Voidbound 内容规格与提示词模板

> 本文档提供怪物 / 技能 / 装备 / 地图的内容规格和提示词模板。  
> 可用 LLM 批量生成具体内容，加速内容设计。

---

## 1. 怪物设计提示词模板

### 通用模板
```
设计一只 [Lv X-Y] 的 [主题] 怪物：
- 名称：[X 风格的名字]
- 外观：[体型 + 颜色 + 特征]（像素 32×32 或 16×16）
- 攻击方式：[近战/远程/召唤]，描述动作
- 词条池：[可能出现的随机词条 3 个]
- AI 行为：[idle / chase / attack / retreat]
- 暴毙掉落物：[金币数量] + [可能装备类型]
- 死亡特效：[粒子类型 + 颜色]
```

### 已生成的示例

#### Boss 怪物

**堕落德鲁伊 (Lv 15)** —— 森林主题 Boss
- 外观：腐烂巨型德鲁伊，藤蔓缠绕，眼睛泛紫
- 阶段：
  - 阶段 1（100%-66% HP）：召唤自然生物 + 藤蔓攻击
  - 阶段 2（66%-33% HP）：召唤树人 + 荆棘光环
  - 阶段 3（33%-0% HP）：狂暴，变身巨型树人，范围攻击
- 特殊：每阶段转换有特殊过场
- 掉落：1-2 传奇装备 + 套装件 + 技能点 × 3

**被诅咒的法老 (Lv 30)** —— 沙漠主题 Boss
- 外观：金色木乃伊法老，缠绕绷带，眼睛发红光
- 阶段：
  - 阶段 1：召唤木乃伊 + 沙暴
  - 阶段 2：召唤沙蝎群 + 火焰护盾
  - 阶段 3：狂暴化，召唤诅咒之灵
- 掉落：2-3 传奇装备 + 套装件 + 技能点 × 5

**堕落天使 (Lv 50)** —— 冰冻主题 Boss
- 外观：白色天使，翅膀残破，眼睛泛黑光
- 阶段：
  - 阶段 1：剑击 + 神圣之光
  - 阶段 2：召唤寒冰骑士 + 冰霜新星
  - 阶段 3：黑化，召唤堕落羽翼，远程 + 近战
- 掉落：3-4 传奇装备 + 套装件 + 技能点 × 8

**虚空之主 (Lv 70)** —— 最终 Boss
- 外观：巨大虚影，无固定形态，多眼多臂
- 阶段：
  - 阶段 1：召唤虚空生物 + 暗影吐息
  - 阶段 2：召唤混沌恶魔 + 现实扭曲
  - 阶段 3：完全虚化，无视 50% 伤害
  - 阶段 4：完全显现，全属性 × 2
- 掉落：所有掉落 × 2 + 终极传奇 + 技能点 × 10

## 2. 技能设计提示词模板

### 通用模板
```
设计 [职业] 的 [等级] 级技能：
- 名称：[X 风格的名字]
- 基础效果：[伤害 + 范围 + 冷却]
- 升级路径：Lv 1-10 → Lv 11-15 → Lv 16-20
- 肉鸽符文变异 × 3：
  1. [变异 A：改变元素 + 新增效果]
  2. [变异 B：改变形态 + 新增效果]
  3. [变异 C：增强 + 新增机制]
- 视觉特效：[粒子 + 颜色 + 持续时间]
- 音效提示：[触发声 + 命中声]
```

### 已生成的示例

#### 法师职业

**火球 (Lv 1)**
- 基础：发射一颗火球，造成 10-15 火伤，冷却 1.5s
- 升级路径：
  - Lv 1-10：伤害 +10%/级
  - Lv 11-15：穿透目标
  - Lv 16-20：分裂为 3 个小火球
- 符文变异：
  - **寒冰之球**：变冰伤 + 减速目标
  - **闪电之球**：变电伤 + 弹射到 3 个目标
  - **熔岩之球**：火伤 + 留下 3 秒燃烧地面
- 视觉：橙红色火球，飞行轨迹带火星

**冰霜新星 (Lv 6)**
- 基础：以自身为中心释放冰霜光环，造成 20-25 冰伤 + 减速，冷却 8s
- 升级路径：
  - Lv 1-10：范围 + 伤害
  - Lv 11-15：冻结 2 秒
  - Lv 16-20：双次释放
- 符文变异：
  - **火焰新星**：变火伤 + 燃烧
  - **暗影新星**：变暗伤 + 易伤
  - **电击新星**：变电伤 + 弹射

**闪电链 (Lv 12)**
- 基础：发射闪电，弹射至 3 个目标，每次弹射伤害 -30%
- 升级路径：
  - Lv 1-10：弹射数 + 1/级
  - Lv 11-15：弹射距离 +
  - Lv 16-20：最终目标眩晕
- 符文变异：
  - **冰霜链**：冰伤 + 减速
  - **暗影链**：暗伤 + 易伤
  - **神圣链**：神圣伤 + 治疗友军

#### 野蛮人职业

**旋风斩 (Lv 1)**
- 基础：原地旋转攻击周围目标，造成 8-12 伤害，冷却 4s
- 升级路径：
  - Lv 1-10：伤害 + 范围
  - Lv 11-15：移动时可释放
  - Lv 16-20：每次命中回复 5 HP
- 符文变异：
  - **烈焰旋风**：火伤 + 留下燃烧路径
  - **电击旋风**：电伤 + 弹射
  - **暗影旋风**：暗伤 + 易伤

**重击 (Lv 6)**
- 基础：强力一击，造成 25-30 伤害 + 击退，冷却 3s
- 升级路径：
  - Lv 1-10：伤害 + 击退距离
  - Lv 11-15：眩晕 1 秒
  - Lv 16-20：双倍范围
- 符文变异：
  - **碎裂重击**：物理 + 地面裂纹（持续伤害）
  - **神圣重击**：神圣伤 + 治疗
  - **虚空重击**：暗伤 + 易伤

#### 死灵法师职业

**骷髅召唤 (Lv 1)**
- 基础：召唤 1 个骷髅战士，持续 30 秒，冷却 10s
- 升级路径：
  - Lv 1-10：骷髅 HP / 攻击 +
  - Lv 11-15：同时召唤 2 个
  - Lv 16-20：骷髅死亡时爆炸
- 符文变异：
  - **火焰骷髅**：火伤 + 攻击带燃烧
  - **冰霜骷髅**：冰伤 + 减速
  - **暗影骷髅**：暗伤 + 易伤

**诅咒 (Lv 6)**
- 基础：对目标施加诅咒，-25% 抗性，持续 10 秒
- 升级路径：
  - Lv 1-10：减抗幅度 +
  - Lv 11-15：范围诅咒（最多 5 个目标）
  - Lv 16-20：诅咒目标死亡时传染
- 符文变异：
  - **元素诅咒**：额外 -25% 单元素抗性
  - **易伤诅咒**：+25% 受到的伤害
  - **虚弱诅咒**：-50% 移动 / 攻击速度

## 6. 提示词批量生成建议

### 使用 LLM 批量生成内容的步骤

1. **复制模板**：复制上述任意模板
2. **填入参数**：替换 `[占位符]` 为具体值
3. **批量生成**：对每个职业 / 怪物 / 装备运行 LLM
