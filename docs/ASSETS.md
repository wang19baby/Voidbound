## 14. 角色染色方案(Kenney → 6 职业)

Kenney Tiny Battle 提供 16×16 角色 + 武器,但只有**4 个通用角色 + 4 个主题色**(蓝/绿/红/黄)。需要重涂 + 装备拼接做出 6 职业区分。

### 14.1 6 职业色板与角色区分

| 职业 | 主色 | 配色(HEX) | 武器 | 配饰 | 备注 |
|------|------|-----------|------|------|------|
| 野蛮人 | 红/棕 | `#8b3a1a` + `#5a2410` | 大剑/双斧 | 红色头巾 | 体型放大 1.1× |
| 圣骑士 | 金/白 | `#d4af37` + `#f5f5f5` | 锤/盾 | 金色头盔 | 持盾手加大 |
| 法师 | 蓝/紫 | `#3a7bd5` + `#5a3a8b` | 法杖 | 蓝色尖帽 | 头顶魔法球 |
| 死灵法师 | 紫/黑 | `#5a1a7a` + `#2d0a3d` | 骷髅杖 | 骷髅肩饰 | 披风拖地 |
| 游侠 | 绿/棕 | `#3a8b3a` + `#8b5a3a` | 弓/弩 | 绿色兜帽 | 背包侧挂 |
| 刺客 | 黑/红 | `#1a1a1a` + `#8b1a1a` | 双匕首 | 红色面罩 | 体型缩小 0.9× |

### 14.2 重涂流程(Aseprite 推荐)

```
1. 打开 Kenney Tiny Battle 原图
2. Sprite > Color Mode > Indexed (锁定调色板)
3. Select > By Color → 选中蓝色像素
4. Edit > Replace Color → 输入新职业主色 HEX
5. 重复 2-4 步骤,逐色替换
6. 导出 sprite sheet (PNG, transparency 启用)
```

### 14.3 装备拼接(同色区分法)

- **野蛮人**:Tiny Battle 斧 + 自绘红色头巾(2 像素覆盖头部)
- **法师**:Tiny Battle 法杖 + 自绘蓝色尖帽(8×8 像素)
- **刺客**:Tiny Battle 匕首 × 2 + 自绘红色面罩(2 像素)

### 14.4 4 方向走法

Tiny Battle 提供 4 方向,够用。如果需要平滑动画:
- 走:每方向 4 帧(交替左脚右脚)
- 攻击:每方向 3 帧(蓄力→释放→恢复)
- 站立:每方向 2 帧(微微呼吸)

### 16.3 工作流(Sprite 32×32 角色)

```
Step 1: 建画布
  File > New > 32x32, Indexed mode, transparent

Step 2: 锁调色板
  Palette > Load Palette > 选择 4 主题调色板(.aseprite 文件)

Step 3: 画站立帧
  Layer 1: 轮廓(主色 2 px 描边)
  Layer 2: 填色
  Layer 3: 高光
  Layer 4: 阴影

Step 4: 动画(Alt+B 新帧,Alt+N 复制)
  - walk: 4 帧
  - attack: 3 帧
  - idle: 2 帧(呼吸)
  - death: 4 帧

Step 5: Onion Skinning 开启
  显示前一帧为半透明,辅助对齐

Step 6: 导出 Sprite Sheet
  File > Export As > Sprite Sheet
  格式: PNG, 排列: Horizontal strip
  → 导出给 Rust game/sprite 加载
```

### 16.4 工作流(Tile 16×16 主题)

```
Step 1: 建画布 256x256(16x16 网格 = 256 tile)
Step 2: 每 16x16 一个 tile
  - 地面 ×3 变体
  - 墙 ×2 变体
  - 装饰 ×5(树/草/石头/花/蘑菇)
Step 3: 用同一调色板
Step 4: 导出 → PNG, 透明背景
```

| 模型 | 来源 | 用途 |

| **Retro Diffusion** | retro-diffusion.github.io | 专门做游戏像素艺术 |

### 17.2 推荐工作流

```
工作流(Stable Diffusion XL + Pixel LoRA):

1. 安装:A1111 / ComfyUI / Forge(任选一)
2. 加载:SDXL base + PixelArtXL LoRA
3. 提示词模板:
   positive: "pixel art, 32x32 sprite, fantasy warrior, 
              dark forest background, top-down view, 
              clean lines, low color count"
   negative: "smooth gradient, photorealistic, 3d render"
4. 参数:
   - Steps: 20-30
   - CFG: 7-9
   - Size: 512x512 (低分辨率强制像素风)
   - LoRA weight: 0.7-0.9
5. 后处理:
   - 用 Aseprite 量化颜色到主题调色板
   - 手绘调整轮廓
   - 输出 32x32 PNG
```
