## 1. 架构级决策（已确认）

### D-01 肉鸽符文的"永久"语义 → **双轨：符文可重铸**

| 维度 | 规则 |
|------|------|
| 单局内 | 变异后**本局永久**绑定到该技能 |
| 拒绝权 | 变异触发后玩家可选择 **"拒绝变异"**，技能保留原版，30% 概率在本局不再触发 |
| 重铸 | 圣城"符文锻造师"消耗材料可**重铸**一个已变异技能，重新随机 3 选 1 |
| 跨局保留 | 通关一局后，玩家可**勾选 1 个变异技能**带入下一局（账号级"传承槽"） |
| 存档影响 | 见 DESIGN.md §9 |

**为什么这样定**：保留 Roguelike 单局新鲜感（Hades 路径），同时通过"传承槽"给玩家轻微的 build 积累（POE 路径），避免纯随机导致成就感缺失。

### D-02 主循环架构 → **混合模式（Rust 物理 + Web 渲染 + 共享环形缓冲）**

```
┌──────────────────────────────────────────────────────────────┐
│                    Rust 端（60Hz fixed timestep）                │
│  - 物理与碰撞检测（rapier 或自实现 AABB）                          │
│  - 伤害公式（权威）                                              │
│  - 存档读写（bincode + 文件锁）                                   │
│  - WFC 地图生成（fast-wfc,生成时一次）                            │
└────────────────────────┬──────────────────────────────────────────────────────────────┘
                         │ Tauri IPC: 共享内存 + command 事件
                         │   写: input → Rust input queue (lock-free ring buffer)
                         │   读: Rust → Web frame snapshot (lock-free ring buffer)
┌────────────────────────┴──────────────────────────────────────────────────────────────┐
│                    Web 端（60Hz requestAnimationFrame）              │
│  - 渲染（WebGL2 全部绘制）                                         │
│  - AI 行为（敌人寻路 / 技能触发 / Boss 阶段机）                      │
│  - 粒子 / 特效 / Buff 光环（高频,GPU instanced）                     │
│  - UI（HUD / 面板 / 弹窗）                                         │
│  - 输入捕获（写回 Rust）                                            │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

**为什么这样定**：
- 粒子 / 视觉特效在 Web 端（避免 IPC 阻塞 Rust 主循环）。
- 物理 / 数值在 Rust 端（避免 JS 浮点漂移 + 反作弊友好）。
- 共享环形缓冲（`ringbuf` crate）做零拷贝帧快照，Tauri 默认 IPC 改造成 `tauri::ipc::Channel`。

**关键依赖新增**：
- Rust: `ringbuf = "0.4"`、`parking_lot`（无锁）
- 移除 DESIGN.md 中提到的"noise 或 fast-wfc"二选一，统一为 `fast-wfc`

### D-03 难度系统 → **全套（词条 + 怪物 + 掉落 + 死亡）**

| 难度 | 怪物 | 词条密度 | 掉落倍率 | 死亡惩罚 | 解锁条件 |
|------|------|---------|---------|---------|---------|
| **普通** | 100% | 0 | 1.0× | 仅本次运行清零 | 默认 |
| **噩梦** | 150% HP / 130% 伤害 | 精英自带 1 词条 | 1.5× | 同上 | 通关森林 |
| **地狱** | 200% HP / 160% 伤害 | 精英 2 词条 / Boss 1 词条 | 2.0× | 同上 | 通关沙漠 |
| **炼狱** | 300% HP / 200% 伤害 | 怪物 2-3 词条 / Boss 多 1 阶段 | 3.0× | 同上 | 通关冰冻 |
| **硬核** | 400% HP / 250% 伤害 | 怪物满词条 / Boss 满阶段 | 5.0× | **账号死亡（不可复活）** | 通关虚空深渊 + 传承槽 ≥ 5 |

**附加规则**：
- 难度选择界面在圣城"难度选择师"处。
- 难度只影响**当前局**，跨局可重新选。
- **玩家限制**仅在"硬核"生效：禁用 1-4 水药（药水栏保留为装饰）。

**为什么这样定**：标准 ARPG 深度（参考 D2R / POE 地图词条），保留玩家可控性。

## 2. 默认提案（待 v1.1 review 敲定）

下面是对 v1.0 中 **21 个未决议题**的默认提案。每个用 `⚠️ 待确认` 标注。

#### D-04 伤害公式（D2R 风格） ✅ 已确认
```
物理伤害 = (基础伤害 + 武器伤害) × (1 + Str/100 + 武器% + 技能%) × 暴击 × 抗性后减成 × 易伤
元素伤害 = 元素基础 × (1 + 主属性/100) × 暴击 × 抗性后减成 × 易伤 × 技能%

暴击：默认 1.5×，与 +暴击伤害% 加法叠加(调高暴击 / 非暴击 build 也能输出)
有效抗性 = clamp(装备抗性 + 技能抗性 + Buff - 减抗, -100, 75)
伤害减免 = 1 - 有效抗性/100（负值时放大伤害）
减抗（如诅咒 -25%）叠加顺序：先减抗 → 后算伤害减免
易伤：1 + 受易伤加成%，单独乘区（受"易伤加成上限 50%"约束）
```

#### D-05 经验与等级曲线
- 等级区间经验公式：`EXP_to_next = 100 × Lv^1.5`（向下取整）
- 单局 30-60 分钟约能升到 **Lv 35-45**
- 虚空深渊（Lv 50+）入口仅限"通关后开启的传承局"或"满级传承局"
⚠️ 待确认：是否允许玩家"超等级"进入低等级主题。

#### D-06 金币经济
- 怪物掉落金币：`base_gold × monster_level × difficulty_multiplier`
- 药水价格：HP 药水 50/瓶，MP 80/瓶（基础难度）
- 装备重铸：100 金币 + 1 材料
- 神秘商人：每局 4 件随机传奇，价格随机 500-2000 金币
- 金币**不跨局保留**
⚠️ 待确认：金币是否应跨局保留。

#### D-07 装备词条池规模
- 属性词条池：~30 个（前缀 + 后缀）
- 攻击词条池：~25 个
- 防御词条池：~25 个
- 特殊词条池：~20 个
- 每件传奇 6-8 词条由上述 100 个池子随机抽取
- **前缀 + 后缀**是同一系统的两个 slot（不是两个分类），独立生成
⚠️ 待确认：词条池是否要在 CONTENT.md 中提前列全。

#### D-08 城镇解锁顺序
- 新手镇：默认
- 商业城：**通关森林主题**（任一职业）
- 圣城：**同时通关沙漠 + 冰冻主题**（并列，不分顺序）
- 城镇间用"传送门"互通（圣城解锁后开启）
⚠️ 待确认：圣城是否要求特定职业通关。

#### D-09 死亡机制（软核）
- 默认"软核"：死亡 → 回到上次城镇，本次运行装备保留 50%（随机丢弃），金币清零
- "硬核"模式：见 D-03
- **装备规则**：死亡后回到城镇，装备可在仓库保留；本次运行背包物品 50% 丢失
⚠️ 待确认：装备丢失比例与丢失策略（随机 vs 低价值优先）。

#### D-10 水药系统
- 4 格药水栏，每格可装备一种药水（HP / MP / 抗性 / 解控）
- 水药来源：怪物掉落（10% 概率）、商店购买（每局限购 20 瓶）、训练师合成
- 1-4 数字键使用对应栏位的水药
- 每瓶 CD：HP/MP 5s，抗性 30s，解控 60s
⚠️ 待确认：每局限购数量。

#### D-11 怪物词条池
- 怪物词条池与装备词条池**不同**，独立 ~40 个怪物专属词条
- 类别：增强型（+HP / +伤害 / +攻速）、减益型（自爆 / 分裂 / 召唤）、特殊型（相位 / 反射 / 抗性）
- 普通怪物不携带词条；精英 1-2 个；Boss 2-3 个
- 怪物词条在生成时随机抽取，独立于装备词条
⚠️ 待确认：怪物词条是否要"抗性词条"与"行为词条"分池。
