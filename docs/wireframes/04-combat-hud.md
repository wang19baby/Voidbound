## 4.7 世界层(全屏)

- 玩家 sprite: `pickPlayerSprite` 决定水平朝向
- 怪物: 4 主题 × 17 怪 + 染色变体
- Boss: 顶栏血条
- VFX: 火花/光环/震屏 (`cameraShake`/`hitStop`)
- 伤害数字: 世界坐标 → 屏幕投影,12-14px
- 精英名牌: 头顶黄色 "精英·XX"
- 地面装备标签: `<700px` 距离内显示装备名+稀有度色

## 4.8 全屏特效层

| 触发 | 效果 |
|------|------|
| 升级 (US-019) | 全屏金光 `rgba(255,215,0,0.30)` + "LEVEL UP → X" 56px |
| 低血量 < 25% | 边缘径向红晕 `rgba(180,0,0,0.35)` |
| 死亡时 (B1) | 进入死亡屏(非强制复活) |
| 施法失败 (OPT-007) | 槽位红闪 0.25s |
| B-V2 Boss 入场 | 横幅 + 全屏泛光脉动 (3 召唤点接线) |
| 命中停顿 (V0) | 0.1s 冻结世界 |
