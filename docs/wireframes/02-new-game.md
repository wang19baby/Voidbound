## 交互矩阵

| 区域 | 键盘 | 鼠标 |
|------|------|------|
| 职业 | `1` ~ `6` 直接选 | 点击职业卡 (300×40) |
| 难度 | `Z` / `X` 步进 (跳过未解锁) | 点击难度卡 (280×36) |
| 主题 | `←` / `→` 步进 | 点击主题卡 (82×72) |
| 模式 | `M` 循环 3 种 | 点击模式卡 (360×36) |
| 开始 | `Enter` | 点击开始按钮 (400×48) |
| 返回 | `Esc` | 点击左上"← 返回" (200×40) |
