## NPC 视觉系统

| 类型 | 视觉 | GL 渲染 |
|------|------|---------|
| 角色 NPC (商人/训练师/仓库...) | 站桩 sprite + 脚底光环 | `npcs` 图集 sprite |
| 难度祭坛 (`difficulty`) | 脉冲光环 52×52 | `ui/slide_horizontal_color` (add blend) |
| 出门传送阵 (`exit`) | 地面贴图 88×88 | `npcs/portal_array` |
| 交互提示 | 头顶 E — XXX | Canvas2D 文字 |

**脉冲动画**: `0.75 + 0.25 * sin(now * 3 + pos.x * 0.01)`,3Hz
**脚底光环**: 32×6 矩形,`near` 时青绿色,默认灰蓝

## 6.4 传送过场 (`drawTeleportTransition`)

`state.teleportT = 1.0s`,触发 `teleportTo` 目标镇:

```
┌──────────────────────────────────────────────────────────────────────┐
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
│                                                                       │
│                                                                       │
│                          ⬤ 扩散光圈 1 (外环)                          │  ← 30+progress*maxR
│                                                                       │
│                          ⬤ 扩散光圈 2 (内环)                          │  ← ringR*0.6
│                                                                       │
│                                                                       │
│                       传送中… 绿翼镇                                │  ← 30px bold #cfe8ff
│                       [1s]                                          │  ← 14px #668
│                                                                       │
└──────────────────────────────────────────────────────────────────────┘
```

- 背景渐入: `rgba(4,6,12, fade)` fade = min(1, progress*2)
- 双层扩散环: 蓝色 0.7/(1-progress),内环 0.5
- 1s 后落地到目标镇

## 状态流转

```
dungeon ──[回城/死亡回城]──→ town ──[E 出门 NPC]──→ newgame (ngFrom='town')
                              │                          │
                              ├──[E NPC]──→ townPanel    └──[Enter]──→ dungeon (新局)
                              │           │
                              │           ├──[Esc/B]──→ town
                              │           └── 触发购买/重铸/存取/升级/传送/锻造
                              │
                              └──[Esc]──→ pause

A-W1 门结算: dungeon ──Boss 击杀──→ 传送门 ──[V]──→ portal panel
                                            └────[1 回城/2 继续]──→
```
