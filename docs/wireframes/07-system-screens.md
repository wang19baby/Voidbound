**触发**: `Esc` 键(dungeon / town)
**背景**: `rgba(0,0,0,0.7)` 全屏

```
┌──────────────────────────────────────────────────────────────────────┐

│                                                                       │
│                           PAUSED                                     │  ← 48px bold #fff
│                                                                       │
│           1 继续 · 2 设置 · 3 主菜单 · 4 城镇 · P 存档                │  ← 20px #ddd
│                                                                       │
│           Ctrl+1..6 分配技能点 · P 存档                              │  ← 14px #777

**交互**:
| 键 | 动作 |
|----|------|
| `1` / `Esc` | 继续 (`resumeScreen`) |

| `3` | 保存并回主菜单 |
| `4` | 进城 (从 dungeon 进暂停时) |
| `P` | 存档 |
| `N` | 切难度 (仅 town 来源暂停,战斗中红字 toast 提示) |

## 7.2 死亡结算 (Death)

**绘制**: `src/main.ts:3000-3070`
**触发**: HP ≤ 0 且 `screen === 'dungeon'`
**背景**: `rgba(120,0,0,0.7)` 全屏(红色)
**死亡撤销窗口**: `state.deathUndo = 5s` (软核免费撤销)

```
┌──────────────────────────────────────────────────────────────────────┐
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
│                                                                       │
│                  YOU DIED     (硬核: 永 久 死 亡)                   │  ← 56px bold
│                                                                       │
│            等级 12 · 总击杀 47 · 最高连击 8                          │  ← 20px
│            金币 234 · 击杀者: 骷髅王                                │  ← 20px
│                                                                       │
│            硬核: 角色进度将清空 (装备/等级/技能/符文)                │  ← 15px (硬核)
│                                                                       │
│         [1] 回城(保留软核进度)                                       │
│         [2] 原地复活(消耗金币)                                       │

**结算数据** (`deathSummary`):
- `level` / `kills` / `maxCombo` / `gold` / `killer` (最近伤害来源) / `hardcore` (bool)

**交互**:
| 键 | 动作 |
|----|------|
| `1` | 回城 → town |
| `2` | 原地复活 → dungeon |
| `3` | 撤销(仅软核 + 5s 窗口内)→ dungeon |

## 屏幕状态机 (`src/game/state.ts:84-93`)

```
title ─[1]─→ newgame ─[Enter]─→ dungeon ─[Esc]─→ pause
   │            │                  │  │             │
   │            │                  │  └──[Tab]─→ equipment ─[Tab/Esc]─→ dungeon
   ├─[R]─→ characters             │
   │            │                  ├─[Boss 击败]─→ (Boss 死亡位) ─[V]─→ portal
   ├─[2]─→ (settings)             │                                    └─[1/2]─→ town/dungeon
   │                               │
   ├─[死/回城]─→ town ─[Esc]─→ pause
   │                │
   │                └─[E 出口 NPC]─→ newgame (ngFrom='town')
   │
   └─[HP≤0]─→ death ─[1/2/3]─→ town/dungeon/dungeon(撤销)
```
