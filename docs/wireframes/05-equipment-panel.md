## 交互矩阵

| 操作 | 键盘 | 鼠标 |
|------|------|------|
| 关闭面板 | `Tab` / `Esc` | 点击 `[Esc] 关闭` (20,20,96,34) |
| 选格 | `←/↑/→/↓` 移动选中 | 点击格子 |
| 翻页 | `PageUp` / `PageDown` | 点击 `←` / `→` 按钮 / 鼠标滚轮 |
| 装备 | `A` | 点击 `[A] 装备` (300,620,110,32) |
| 卸下 | `U` | 点击 `[U] 卸下` (430,620,110,32) |
| 对比 | 选中时自动 | hover 自动 |

## 视觉细节

- **未装备**: 虚线边框 `[4, 3]`,`#556` 1.5px,内填充 `#232330`,显示"(空)"
- **已装备**: 实线边框 = 装备稀有度色 (`RARITY_COLORS`),3px,内填充 = 装备色 35% alpha,显示槽名首字 + 战力+
- **稀有度色**: 普通白/魔法蓝/稀有金/暗金橙/传奇紫/远古青 (参见 `equipment.ts:RARITY_COLORS`)
- **Tooltip 战力对比**: 绿(`#4f4`)正差 / 红(`#f66`)负差 / 灰(`#aaa`)持平
- **分页提示**: 12px `#889`
