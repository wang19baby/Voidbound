**布局常量**:
- 主菜单 y 基线 = `hudCanvas.height/2 - 30`
- 菜单项间距: 40px
- 单项矩形: 320×38,中心对齐
- 按下响应: `lmbDown` 时 描边 2px 蓝
- hover: 鼠标 cursor → `pointer` (由 `uiCursor(menuRects)`)

**键盘等价**:
| 键 | 动作 |
|----|------|
| `1` | 新游戏 → `setScreen('newgame')` |
| `2` | 设置 → `settingsOpen = !settingsOpen` |
| `R` | 角色管理 → `setScreen('characters')` |
| `Esc` | 关闭设置面板 (如已开) |

**继续游戏按钮细节**:
- 颜色 `#ffd64a`,描边粗细随 hover/down 切换(1/2/3px)
- 摘要行: 职业名 + 角色 ID + 等级 + 主题 + 难度
- 数据源: `state.charList.find(c => c.id === state.currentChar) ?? state.charList[0]`
