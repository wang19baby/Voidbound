## 0. 启动验证 (1 项)

- [ ] Tauri 窗口**居中弹出**（1280×720），无错误

- [ ] JS console 无错误（右下角日志面板显示 `[atlas] PNG decoded + textures uploaded`）

## 1. 渲染管线 (3 项)

- [ ] 屏幕背景：**dungeon stone** 深灰地板（dungeon tile，非草地）
- [ ] 玩家：始终在**视口正中心**，无任何旋转/镜像（固定朝下）
- [ ] 怪物可见：5 只（2 bat + 2 slime + 1 worm），每只头顶 HP 条

---

## 2. 地图系统 (3 项)

- [ ] **无边界感**：走任何方向都看不到世界尽头（world 20480×11520）
- [ ] **程序化分块**：跨过 chunk 边界时墙布局变化（不同种子生成不同图）
- [ ] **墙碰撞**：用 WASD 撞墙→角色沿墙滑移（不能穿墙）

---

## 3. WASD 移动 (4 项)

- [ ] 按 W → 角色向上移动，地面向下滚动
- [ ] 按 S/D/A → 同理其他方向
- [ ] 同时按 W+D → 斜向右上，速度与单方向相同（归一化验证）
- [ ] **alt-tab 切走再切回**：角色立即停下（验证 P0 resetKeys）

---

## 4. 角色朝向（Diablo 风格）(4 项)

- [ ] **鼠标在角色右侧** → 角色 sprite **朝右**（不翻转）
- [ ] **鼠标在角色左侧** → 角色 sprite **朝左**（水平翻转）
- [ ] **鼠标在中心 ±8px** → 用 A/D 决定朝向（D → 右，A → 左，无 → 默认朝下）
- [ ] **完全没按任何键 + 鼠标在中心** → 角色保持默认朝下，无乱七八糟旋转

---

## 5. 火球技能 (Q 键) (4 项)

- [ ] 按 Q → 从角色位置朝**鼠标方向**发射紫色 magic_01 火球
- [ ] 火球撞**墙**立即消失（`[combat] fireball hit 1 wall(s)`）
- [ ] 火球撞**怪物**：扣 25 HP（bat 30 一击秒，slime 60 两击）
- [ ] 火球飞**出世界边界**自动消失（`[skill] fireballs remaining: 0`）

---

## 6. 近战技能 (LMB / RMB) (4 项)

- [ ] **左键点击** → 角色前方挥击，slash 粒子闪现 ~0.18s
- [ ] **右键点击** → 同样挥击（默认与左键同 melee）
- [ ] 近战**命中怪物**：扣 50 HP（一击秒 bat / slime / worm）
- [ ] 近战**击中火球**：火球被销毁（`[combat] melee destroyed 1 fireball(s)`）

---

## 7. 怪物系统 (5 项)

- [ ] 怪物**远离玩家 600-1200px** 出生（不在视野里突然出现）
- [ ] 怪物在玩家进入 **aggroRange** 后开始追击
- [ ] 怪物**撞墙会绕路**（不再穿墙）
- [ ] 怪物撞到玩家扣 contactDmg（bat 5 / slime 8 / worm 6），1s cd
- [ ] 玩家**生命** < 100 时看到扣血，HUD 顶部红条减少

---

## 8. 战斗 + 分数 (3 项)

- [ ] 击杀后分数 +score（bat 10 / slime 15 / worm 12），HUD SCORE 数字更新
- [ ] 怪物**少于 3 只时随机重生**（地图始终有怪可打）
- [ ] HUD **KILLS** 显示当前怪物总数
