> 版本：v1.0  
> 日期：2026-08-08  
> 状态：已批准

---

## 设计概览

### 游戏定位
- **类型**：2D 俯视 ARPG + Roguelite
- **单局时长**：30-60 分钟
- **永久进度**：解锁新职业、新城镇、新地图主题
- **核心循环**：进入随机地下城 → 打怪刷装 → 升级技能 → 打 Boss → 返回城镇 → 强化/出售/学习新技能 → 再挑战更高难度

### 与 D2R 的核心差异（创新点）
1. **地图完全随机**：WFC 算法生成每次都不同的地下城
2. **多主题地形**：暗黑森林 / 灼热沙漠 / 冰冻废墟 / 虚空深渊，每个主题独立词条池
3. **肉鸽符文系统**：技能树升级时随机出"变异符文"，改变技能效果
4. **多城镇中心**：3 个不同风格的城镇作为永久基地
5. **永久死亡 vs 软核**：可选难度，影响收益

## 系统设计（10 大模块）

### 1. 角色系统（6 个职业）

| 职业 | 定位 | 主题色 | 主属性 | 经典技能代表 |
|------|------|--------|--------|------------|
| 野蛮人 (Barbarian) | 近战坦克 | 红色 | 力量/体质 | 旋风斩、重击、狂战士 |
| 圣骑士 (Paladin) | 坦克/辅助 | 金色 | 力量/信仰 | 祝福之锤、圣盾、复仇 |
| 法师 (Sorceress) | 远程玻璃炮 | 蓝色 | 智力 | 火球、冰霜新星、闪电链 |
| 死灵法师 (Necromancer) | 召唤/诅咒 | 紫色 | 智力 | 骷髅召唤、诅咒、骨墙 |
| 游侠 (Ranger) | 远程物理 | 绿色 | 敏捷/体质 | 多重射击、陷阱、闪避 |
| 刺客 (Assassin) | 高速爆发 | 黑色 | 敏捷 | 影分身、陷阱、连击 |

**每个职业规格**：
- 基础属性 6 项：力量 / 敏捷 / 体力 / 智力 / 信仰 / 魅力
- 主动技能 5 个，被动技能 10 个
- 1 个专属终极技能（30 级解锁）
- 专属装备类型（如法师：法杖 + 魔法符 + 盾）

---

### 2. 怪物系统（30+ 种）

按生态主题分组：

#### 暗黑森林主题（Lv 1-15）
- **小怪**：僵尸幼崽、毒蜘蛛、暗影狼
- **精英**：瘟疫熊、剧毒蜘蛛女王
- **Boss**：堕落德鲁伊

#### 灼热沙漠主题（Lv 15-30）
- **小怪**：沙蝎、火蜥蜴、骷髅兵
- **精英**：火焰巨人、烈焰凤凰
- **Boss**：被诅咒的法老

#### 冰冻废墟主题（Lv 30-50）
- **小怪**：冰霜元素、寒冰僵尸、狼人
- **精英**：霜巫妖、远古冰龙
- **Boss**：堕落天使

#### 虚空深渊主题（Lv 50+）
- **小怪**：虚空行者、混沌恶魔、梦魇
- **精英**：深渊领主、虚空幼龙
- **Boss**：虚空之主（最终 Boss）

**通用怪物属性**：
- 等级、HP、护甲、攻击、攻速、移动速度
- 词条池（怪物也可能随机获得词条，如"火抗"+50%）
- AI 行为模式：近战追击 / 远程攻击 / 召唤型 / Boss 阶段变换

### 3. 城镇系统（3 个永久基地）

| 城镇 | 风格 | 功能 | 解锁条件 |
|------|------|------|---------|
| **鲁特·格莱宁** (新手镇) | 中世纪村庄 | 基础商店、铁匠、学徒训练师 | 默认 |
| **卡斯特蓝港** (商业城) | 海港都市 | 高级商店、神秘商人、装备重铸师 | 通关森林主题 |
| **圣所·阿卡拉** (圣城) | 神圣遗迹 | 终极训练师、符文锻造、难度选择 | 通关沙漠+冰冻主题 |

**城镇设施**：
- 商店（4 种：药水/卷轴/材料/随机装备）
- 训练师（学习/升级技能，消耗技能点）
- 神秘商人（每次提供 4 个随机传奇装备，价格随机）
- 装备重铸师（重铸词条，消耗材料）
- 符文锻造师（合成肉鸽变异符文）
- 仓库（跨局共享存储）
- 难度选择（影响掉落倍率）

---

### 4. 地图系统（WFC 算法随机生成）

**地图主题 × 4**：暗黑森林 / 灼热沙漠 / 冰冻废墟 / 虚空深渊

**WFC 生成参数**：
- 网格大小：80×80 tile
- Tile 类型：地面 / 墙 / 水 / 岩浆 / 冰 / 传送门 / NPC / 宝箱
- 约束规则（相邻 tile 的合法组合）：例如"水"两侧不能是"墙"
- 房间类型：小怪房 / 精英房 / Boss 房 / 商店 / 宝箱房 / 休息点

**地图结构**：
```
[起始房间] → [小怪区 × 3] → [精英房] → [Boss 房] → [传送门返回城镇]
```

**视觉差异**：每个主题独立 tile 集 + 调色板 + 环境粒子（森林：萤火虫；沙漠：风沙；冰冻：飘雪；虚空：黑色尘埃）

---

### 5. 装备系统

**装备槽位**（8+3 个）：
- 头盔 / 项链 / 胸甲 / 主手武器 / 副手 / 手套 / 腰带 / 鞋子
- 戒指槽 2 个 + 护身符槽 1 个

**装备稀有度**（D2R 风格）：
| 稀有度 | 颜色 | 词条数 | 掉落率 |
|--------|------|--------|--------|
| 普通 (Normal) | 白色 | 0 | 50% |
| 魔法 (Magic) | 蓝色 | 1-2 | 30% |
| 稀有 (Rare) | 黄色 | 3-5 | 15% |
| 套装 (Set) | 绿色 | 4-6 | 4% |
| 传奇 (Unique) | 金色 | 6-8 | 1% |

**词条系统**：
- **属性词条**：+力量、+敏捷、+HP、+法力
- **攻击词条**：+最小/最大伤害、+攻击速度、+暴击率、+暴击伤害
- **防御词条**：+护甲、+抗性、+格挡、+闪避
- **特殊词条**：吸血、反弹、法力偷取、击退、生命偷取
- **词条前缀/后缀**：每个词条由前缀（如"锋利的"+伤害）和后缀（如"巨鹰"+敏捷）组合

**套装系统**：
- 每个套装 3-6 件
- 穿 2/3/4 件触发不同套装效果
- 例："暗影套装" 3 件：+30% 暗影伤害，移动时隐身

---

### 6. 技能系统（树 + 符文变异）

**技能树结构**（每职业）：
```
Lv 1:  基础技能 [火球] → 解锁 1 个分叉
Lv 6:  分叉技能 A [烈焰风暴] 或 分叉技能 B [陨石]
Lv 12: 终极技能 [元素大师]
Lv 18: 觉醒技能 [元素领主]
Lv 24: 终极觉醒 [世界之火]
```

**每个技能等级**：
- 1-10 级：基础效果增强（伤害 +10%/级）
- 11-15 级：解锁特殊机制（穿透 / 弹射 / 多目标）
- 16-20 级：解锁终极强化

**肉鸽符文变异**（核心创新点）：
- 技能达到 10 级后，每次升级有 30% 概率触发"变异"
- 变异时随机从 3 个"符文"中选择 1 个，永久改变技能效果
- **变异示例**（火球）：
  - 火球 → **寒冰之球**（变成冰伤 + 减速）
  - 火球 → **闪电之球**（变成电伤 + 弹射）
  - 火球 → **暗影之球**（变成暗伤 + 穿透）
  - 火球 → **熔岩之球**（火伤 + 留下燃烧地面）

**被动技能**：
- 10 个被动槽位（同时生效）
- 例：+生命上限、+法力恢复、+抗性、+闪避、+暴击率

---

### 7. 战斗系统

**操作**：
- **WASD**：八方向移动（斜向速度归一化）
- **鼠标左键**：主技能（默认 Lv1 技能）/ 拾取物品
- **鼠标右键**：副技能 / 强制移动
- **Q / W / E / R**：4 个技能槽（玩家分配技能到这 4 个键）
- **空格**：翻滚（短距离位移 + 短暂无敌）
- **1-4**：使用药水栏

**伤害公式**：
```
最终伤害 = 基础伤害 × (1 + 力量/100) × (1 + 武器伤害加成)
          × 暴击倍率 × 抗性减成 × 易伤加成 × 技能加成
```

**元素抗性**：火/冰/电/毒/暗/神圣 6 系，每系上限 75%

**特殊机制**：
- 击退、击飞、减速、定身
- 持续伤害（DOT）：燃烧/中毒/流血
- Buff / Debuff 系统

---

### 8. 粒子 & 特效系统（WebGL 高性能路线）

**粒子类型**：
- 弹道子弹（500-2000 个同时存在）
- 命中粒子（每次命中触发 5-20 个）
- 环境粒子（地图持续特效，500 个）
- Buff 光环（玩家/怪物头顶）
- Boss 阶段特效（屏幕级）

**性能优化**：
- **Texture Atlas**：所有粒子用一张 1024×1024 图集
- **Instanced Rendering**：单次 draw call 绘制上千粒子
- **粒子池**：对象池复用，避免 GC
- **GPU 粒子**：1 万+ 粒子走 GPU 计算着色器

**着色器特效**：
- Bloom（发光）
- Screen Shake（震屏）
- Distortion（扭曲）
- Light System（局部光照）
- Pixel-perfect 渲染（像素风）

---

### 9. 存档系统

**存档层级**：
- **角色存档**：职业、等级、装备、技能、永久天赋
- **永久进度**：解锁的城镇、训练师、难度
- **本次运行**：当前地图、HP、技能冷却、背包（死亡丢失）

**存储位置**：Tauri 文件系统，存到 `%APPDATA%/voidbound/saves/`

**格式**：JSON（开发期） → 二进制（生产期）

---

### 10. UI 系统

**HUD（战斗界面）**：
- 左上：HP/MP 条 + 等级 + 经验条
- 右上：小地图 + 当前任务
- 左下：技能栏 QWER + 翻滚图标 + 1-4 药水栏
- 右下：怪物血条（精英/Boss）

**界面**：
- 角色面板（属性/装备/技能）
- 背包（40 格）
- 商店
- 城镇地图
- 死亡/胜利结算
- 主菜单

```
│   │   └── camera.ts          # 摄像机
│   ├── game/

│   │   ├── loop.ts            # 游戏循环
│   │   └── ui.ts              # HUD 渲染
│   └── assets/                # 像素图集、shader
├── package.json
└── README.md
```

### 核心依赖
**Rust 端**：
- `tauri = "2.0"`
- `serde` / `serde_json`：序列化
- `rand`：随机生成
- `noise` 或 `fast-wfc`：WFC 算法
- `glam`：向量数学

**Web 端**：
- 原生 TypeScript（无框架）
- 原生 WebGL2（无 Three.js）
- `gl-matrix`：矩阵运算

### 数据流
```
玩家输入 (WASD/QWER/鼠标)
    ↓
前端 input.ts 捕获
    ↓
Tauri command 发送到 Rust
    ↓
Rust 端 game/core 计算（移动/技能/伤害）
    ↓
返回状态变更（HP/位置/粒子事件）
    ↓
前端 render 接收 + 渲染
    ↓
WebGL 绘制下一帧
```

## 验证方法

实施完成时，按以下顺序验证：

1. **编译验证**：`cargo build` + `npm run build` 必须通过
2. **基础渲染**：能看到一个红色方块（玩家）在黑色背景上响应 WASD 移动
3. **WebGL 粒子**：渲染 1000 个粒子，60 FPS
4. **Tauri 通信**：前端发"开火"命令，Rust 返回 3 个粒子事件
5. **技能系统**：按 Q 释放火球，屏幕出现飞行粒子
6. **存档系统**：杀死 5 个怪物后重启，HP/位置/击杀数保留
7. **WFC 生成**：进入游戏每次地图不同但都连通

## 风险与权衡

| 风险 | 应对 |
|------|------|
| WFC 实现复杂 | 用现成 `fast-wfc` crate，先用预制房间验证 |
| 像素图集美术量大 | 先做程序化生成的占位图，后期替换美术 |
| 性能瓶颈 | 早做基准测试（5000 粒子 60FPS 为合格线） |
| 内容设计工作量大 | 用提示词模板批量生成 LLM 内容 |
