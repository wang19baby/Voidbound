## 阶段 1：MVP（2 周）

### 目标
验证 Tauri + Rust + WebGL2 技术栈可行，跑通"移动 → 技能 → 击中怪物 → 伤害"核心循环。

### 第 1 周：基础设施

#### Day 1-2：Tauri 项目初始化
- [ ] 初始化 Tauri 2.x 项目
- [ ] 配置 `Cargo.toml` 和 `package.json`
- [ ] 设置 WebGL2 上下文
- [ ] 验证 `cargo build` + `npm run dev` 启动

#### Day 3-4：基础渲染
- [ ] 渲染一个红色方块（玩家占位）
- [ ] 实现 60 FPS 游戏循环
- [ ] 摄像机跟随

#### Day 5-7：玩家移动
- [ ] WASD 输入捕获
- [ ] 八方向移动（斜向速度归一化）
- [ ] 边界检测（不走出地图）

**第 1 周验收**：玩家在黑色背景上能流畅 WASD 移动

### 第 2 周：核心战斗

#### Day 8-9：技能系统骨架 + **主循环架构决策点（v1.1 D-02 关键）**
- [ ] 定义技能数据结构（伤害 / 冷却 / 范围）
- [ ] **决策**：确认 Rust / Web 边界（混合模式 = Rust 物理 + Web 渲染 + 共享环形缓冲）
- [ ] 初始化 `ringbuf` 共享内存，定义帧快照格式
- [ ] 实现 Q 键释放"火球"
- [ ] 火球飞行 + 生命周期（Rust 端计算位置，Web 端渲染）

#### Day 10-11：碰撞与伤害
- [ ] 火球与敌人碰撞检测
- [ ] 伤害计算公式
- [ ] 敌人 HP 扣减与死亡

#### Day 12-14：基础怪物
- [ ] 一个简单怪物（站立不动的靶子）
- [ ] 怪物死亡掉落金币
- [ ] 粒子特效（火球命中粒子）

**第 2 周验收（M1 里程碑）**：
- [ ] Tauri + WebGL2 项目能成功编译运行

## 风险与缓解（v1.1 更新）

| 风险 | 等级 | 触发阶段 | 缓解策略 |
|------|------|---------|----------|
| Tauri 框架学习曲线 | 低 | M1 | 第一周专注熟悉，不求功能多 |
| **混合 IPC 架构复杂度** | **高** | **M1-M2** | **Day 8-9 决策点；预先写好共享缓冲协议 spec；M2 跑通端到端压力测试** |
| WFC 实现复杂 | 高 | M3 | 用 `fast-wfc = "3"`（统一版本 D-23）；先用预制房间验证连通性；fallback 用预制拼接 |
| 性能瓶颈 | 中 | M4 | M1 就引入基准测试；5000 粒子 60FPS 为合格线 |
| 内容设计工作量大 | 中 | M2-M3 | 用 `docs/CONTENT.md` 中的提示词模板批量生成 |
| 像素图集美术量大 | 中 | 全部 | **多图集策略（D-14）**：分主题 / 分类型打包；先程序化占位 |
| 跨平台打包问题 | 中 | M4 | 提前一周开始测试打包 |
| **难度平衡** | 中 | M2-M3 | 难度系统 D-03；M2 第 4 周做小规模内测；M3 调参 |
| **跨局传承槽设计** | 中 | M3 | D-01 双轨规则；通关结算界面加传承勾选 |
