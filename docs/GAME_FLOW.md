## 1. 启动 → 主菜单

### 1.1 应用启动序列

```
Step 1: Tauri 加载 (1-3s)
  - 显示 splash 画面:logo + 进度条
  - 加载 Rust 端 game core (共享环形缓冲初始化)
  - 加载 Web 端 WebGL2 上下文

Step 2: 检查存档目录
  - Rust 端扫描 %APPDATA%/voidbound/saves/
  - 检测到有效存档 → 预加载存档元数据 (角色列表 + 永久进度)
  - 无存档 → 跳过,显示"创建你的第一个角色"

Step 3: 进入主菜单 (M0)
```

### 2.4 角色命名 (N2)

```
┌────────────────────────────────────────────────┐
│ 为你的角色命名                                  │
├────────────────────────────────────────────────┤
│                                                │
│  职业: 法师                                     │
│  难度: 噩梦                                     │
│                                                │
│  名字: [____________________]  ← 输入框       │
│                                                │
│  ⚠ 名字必填(v1.1 D-25 已确认)                  │
│  1-20 字符,允许中英文 / 数字 / 下划线          │
│                                                │
│  [← 上一步]                  [创建 →] (禁用)  │
└────────────────────────────────────────────────┘
```

**命名规则**(v1.1 D-25 必填):
- **必填**:玩家必须输入名字才能继续
- 1-20 字符
- 允许中英文 / 数字 / 下划线
- 不允许特殊字符 `< > : " / \ | ? *`
- 失败提示友好:"名字必填(1-20 字符)"
- 玩家后续可在"角色管理"界面重命名

### 2.5 创建确认 (N3)

```
┌────────────────────────────────────────────────┐
│ 确认创建                                        │
├────────────────────────────────────────────────┤
│                                                │
│  职业: 法师    名字: 阿萨兹                    │
│  难度: 噩梦                                     │
│                                                │
│  ⚠️ 第一次玩推荐选"普通"难度                   │
│                                                │
│  [← 上一步]                  [确认创建 →]       │
└────────────────────────────────────────────────┘
```

**数据流**:
```
Rust 端:
  - 创建角色存档 (角色ID = UUID)
  - 写入: 职业 / 等级 1 / 装备空 / 经验 0 / 永久进度继承账号级
  - 写入: 本次运行 (HP/MP/技能/背包空)
  - 写入: 当前难度
  - 保存到 %APPDATA%/voidbound/saves/<character_id>.bin
```

## 5. 存档管理界面 (内嵌在角色管理)

### 5.1 存档导入 / 导出

```
[导出存档]: 保存到 .voidsave 文件 (JSON + bincode 压缩)
[导入存档]: 选择 .voidsave 文件 → 校验 → 添加到列表
[删除存档]: 二次确认 → 永久删除

每个角色的存档独立,可独立操作。
```

### 5.2 存档目录结构

```
%APPDATA%/voidbound/saves/
├── characters/
│   ├── <uuid-1>.bin         # 角色 1 完整存档
│   ├── <uuid-2>.bin         # 角色 2
│   └── ...
├── account.bin              # 账号级数据(已解锁城镇/传承槽/全局设置)
├── settings.json            # 用户设置(音量/分辨率/键位)
└── backup/
    └── 2026-08-08/          # 自动备份(每日)
```

### 6.2 NPC 设施交互

每个 NPC 触发独立 UI:

| NPC | 快捷键 | 打开界面 |
|-----|--------|---------|
| 商店 | N | 商店界面 (4 种商品:药水/卷轴/材料/随机装备) |
| 训练师 | T | 技能学习/升级 |
| 仓库 | W | 跨局共享存储(100 格) |
| 神秘商人 | M(在商业城) | 4 件随机传奇装备 |
| 重铸师 | R(在商业城) | 装备词条重铸 |
| 符文锻造师 | F(在圣城) | 符文重铸 + 变异合成 |
| 难度选择师 | D(在圣城) | 切换难度 |
| 出口 | → | 跳转到主题选择 (T2) |

### 6.3 城镇间传送

```
新手镇 ⇄ 商业城 (通关森林后开启)
商业城 ⇄ 圣城 (通关沙漠+冰冻后开启)
新手镇 ⇄ 圣城 (圣城解锁后开启)
```

**传送方式**:
- 走到 NPC "传送师" → 选择目标城镇 → 2 秒过场 → 到达
- 或在城镇地图 UI 点击目标城镇

## 14. 边界情况

| 情况 | 处理 |
|------|------|
| 存档损坏 | 检测到 CRC 失败 → 提示"存档损坏,加载备份" |
| 无可用备份 | 提示"存档无法读取,是否删除" |
| 同名角色创建 | 提示"已有同名角色,是否覆盖/重命名" |
| 难度已超过等级上限 | 提示"推荐先升级到 Lv X" |
| 退出到主菜单时正在战斗 | 二次确认"放弃本次进度?" |
| 切换难度时正在战斗中 | 不允许(回城后才能改) |
| 网络断开(单机,无影响) | N/A |
| 磁盘空间不足 | 提示"存储空间不足,无法保存" |

## 15. M1 启动时的最小流程集

```
M1 必做:
  - 应用启动 + splash
  - 主菜单(只有"新游戏"和"退出")
  - 职业选择(6 卡,但只有野蛮人有内容)
  - 难度选择(只"普通")
  - 跳过命名,系统生成
  - 直接进入新手镇(空场景 + 一个 NPC = 出口)
  - 出口 = 进入一个固定地图(WFC 后做)
  - 战斗界面(WASD + 火球 Q + 一个站立怪物)
  - 死亡 → 主菜单
  - 主菜单关闭

M1 不做:
  - 继续游戏
  - 角色管理
  - 存档管理(导入导出)
  - 设置
  - 通关结算
  - 传承槽
```
