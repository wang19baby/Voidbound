# Voidbound 玩家体验优化需求文档(10 轮头脑风暴产物)

> 版本:v1.0
> 日期:2026-08-10
> 状态:拍板完成(A1/B1/C1 已确认,2026-08-10)

> 用途:将确认的问题与优化固化为可实施需求;实施时同步回填 `prd.json`(US-xxx + acceptanceCriteria + passes)

---

## 1. 背景与目标

游戏已具备可玩闭环:M1 核心(WASD + 火球/近战 + 分块世界)+ M2 批量内容(伤害公式地基、5 档难度、装备/套装、符文三选一、主题怪 + 4 Boss、城镇 4 NPC、存档)。

10 轮头脑风暴按玩家旅程逐段审计后确认:**核心战斗可玩,但"局的骨架"缺失(无终点/无死亡选择/无经济闭环)、数据有 P0 级丢档风险、数值存在明显失衡(MP 无限回蓝)、内容差异化靠染色撑数、工程护栏不足**。

本文档将所有问题固化为 34 条需求(OPT-001 ~ OPT-034),分 5 波实施。

## 3. 需求条目

> 编号 OPT-xxx;`来源` 指向问题 ID;**验收标准为可执行判断**,实施时逐条回填 `prd.json`。

### Wave 0 — 数据安全与文案快修(无拍板依赖,半天 ~ 1 天)

#### OPT-001 失焦自动暂停
- **来源**:P-01 | **严重度**:P0
- **需求**:文档/窗口失焦(visibilitychange + blur)→ 自动 `paused=true`;恢复焦点后保持暂停,需手动继续;设置面板开关(默认开)。
- **验收标准**:
  - [ ] Alt-Tab 后游戏暂停,怪物/回血/计时器全部冻结
  - [ ] 回到游戏需手动"继续"恢复
  - [ ] 设置可关闭此项
- **涉及文件**:src/main.ts(visibilitychange listener)、暂停菜单
- **依赖**:—

#### OPT-002 退出/回菜单自动保存 + 确认
- **来源**:P-02 | **严重度**:P0
- **需求**:暂停菜单"返回主菜单"与窗口关闭前自动 `saveGame` 并二次确认;暂停菜单新增"保存并退出";保存失败必须提示,不得静默。
- **验收标准**:
  - [ ] 直接关窗 → 自动保存后退出
  - [ ] 回主菜单 → 确认后保存再回
  - [ ] 保存失败明示错误,不静默
- **涉及文件**:src/main.ts、ipc/save.ts
- **依赖**:—

#### OPT-003 存档数据完整性:技能等级/技能点/EXP 持久化

- **验收标准**:
  - [ ] 存盘 → 杀进程 → 读档:技能等级/技能点/EXP 完全一致
  - [ ] skill.ts 提供还原入口(restoreSkillLevels),load 路径调用

- **涉及文件**:src-tauri/src/save.rs、src/main.ts(O 读档块)、src/game/skill.ts

#### OPT-004 存档版本头 + 迁移

  - [ ] 硬核死亡 = 清档重开(语义不变)

#### OPT-012 单层地牢 + 通关结算 + 再来一局
- **来源**:P-33、P-23 | **严重度**:P1 | 一局骨架
- **需求**:主题 = 一局地牢:进入时按主题池生成有限怪物群(数量上限,如 24),**取消战斗中 ≥3 保底重生**;清空当前群 + 击杀主题 Boss → 通关结算页(时间/击杀/掉落统计/难度)+ [再来一局(同难度,直接重开)] [回城];最佳时间按难度分桶记录(HUD 可查)。
- **验收标准**:
  - [ ] 清图 + Boss 击杀触发通关结算,不会无限刷怪
  - [ ] "再来一局"直接重开当前主题同难度,无需回城
  - [ ] 最佳时间持久化(随 OPT-004 版本头)
  - [ ] Boss 触发从"任意地点 10 连杀"改为地牢关底语境(结算前置条件)
- **涉及文件**:src/main.ts(重生逻辑重构)、src/game/monster.ts(池容量)、src/game/state.ts(跑局状态:剩余怪/计时)、ipc/save.rs(best_time)
