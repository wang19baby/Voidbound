## 1. 背景与目标

游戏已具备完整战斗闭环:M1 核心 + M2 内容波次(伤害公式 D-04 / 5 档难度 / 装备词条 / 符文三选一 / 17 怪 / 4 主题 Boss / 城镇 NPC / 存档 v9)。**玩法深度与表现力是下一阶段主线**。

头脑风暴确认的现状约束:

- 地图 = chunk 方块迷宫(8×8 块 / 1024px,边界环空 + 十字走廊 + 18% 随机密度),唯一不变式是"任意 chunk 连通"——无房间、无区域、无地标,"方方正正"。
- 怪物 = 24 只平铺随机撒,精英仅 8% 随机染色(HP×2.2/伤×1.5),Boss 由 10 连杀触发(纯时间,与地图零关系),无"群落/领主"概念。
- 战斗手感/决策空间小:怪物机制仅 dash/split 两种小怪 AI + summon/ring/charge 三种 Boss 技能。

设计目标(拍板):**三模式地图(玩家自选布局)+ 五层怪物层级(全地图通用)+ 门/结算机制 + 机制扩展包(全量上)**。画质提升为并行主线,不阻塞本设计实施。

## 2. 三模式地图(玩家自选)

> 新局选择屏增加**布局模式**选项(1 普通 / 2 高级 / 3 挑战),存档记录 mode 字段(存档版本 v9→v10,迁移默认普通)。三模式共用现有 chunk 骨架,新增**地标雕刻 pass**。

### 2.1 地图1 · 普通(线性 + 分支)

- **结构**:出生在左,主轴左→右,终点右端最终 Boss;**禁止一字型**——主线沿途挂分支。
- **分支内容**:宝藏密室 / 精英营地 / 可选强化点。
- **生成规则**:**简化 WFC**(非完整 WFC,真 WFC 留 M3):一条主走廊 + 随机宽度房间分支 + 喉点(窄通道),产出"手作感"的有机布局。
- **门数**:1(右端最终 Boss)。

### 2.2 地图2 · 高级(承诺制)

- **结构**:**随机角落入口**(防背板),外→内递进,目标 = 中央最终 Boss。
- **四角领主**:四个角落各 1 个领主 + 精英护卫群(群落守卫层),**不给门**。
- **性格**:**承诺制**——路上所有战斗都不给撤退点,只有中央最终 Boss 给门;进入后死或通关。
- **地形**:随机有机形状,从外往里密度与强度递增。

### 2.3 地图3 · 挑战(提取制)

- **结构**:中央出生 → 向外推进,四个方向区(白怪→增强→精英→领主),区尽头各 1 个**元素 Boss**。
- **最终 Boss**:4 个外向元素 Boss 全清后,在中央(出生区,变成竞技场)登场——从哪出发,回哪决战。
- **性格**:**提取制**——每个 Boss 死亡位置都生成门(4 外向 + 1 终 = 5 门),击杀 ≥1 即可随时撤退。
- **收益**:全清 + 最终 Boss 奖励峰值;中途撤退只拿已击杀部分。

### 2.4 地图生成规则(通用)

| 规则 | 实现 | 成本 |
|---|---|---|
| 密度梯度 | 墙密度 = f(距出生点/距巢穴距离),近开远密 | 便宜(RNG 参数) |
| 地标雕刻 | 生成 chunk 后清空一块区域 + 砌墙围边(营地/巢穴/竞技场),覆盖均匀撒墙 | 便宜(雕刻 pass) |
| 走廊变化 | 收窄成喉点(1 块宽)、加宽成大厅;保留边界环连通不变式 | 便宜 |
| 死路密室 | 偶发死路 pocket 藏宝藏;数量上限防迷路 | 便宜 |
| 简化 WFC | 仅地图1 主轴:主走廊 + 随机房间分支 | 中 |

## 3. 门与结算

- **门生成位置 = Boss 死亡位置**,生成回城交互点;交互弹面板 **[回城 / 继续]**;门持续到本局结束。
- **门数**:普通 1(右端)/ 高级 1(中央)/ 挑战 5(4 外向 + 1 终)。
- **通关判定(三模式统一)**:最终 Boss = 通关结算。
- **中途回城 = 提前结算**:战利品 / 经验 / 材料保留,但拿不到全清奖励(最终 Boss 掉落 / 通关加成),本局结束。
- 回城后城镇/仓库逻辑复用现有设施;硬核难度语义不变。

## 4. 五层怪物层级(全地图通用)

| 层级 | 定义 | 数值基准 | 掉落 |
|---|---|---|---|
| **普通** | 白怪,散落填充 | 现 17 种底模 | 基础 |
| **增强** | 被光环强化的白怪 + 偶发独立强化怪 | ~1.4× 白怪 | 基础+ |
| **精英** | 营地头目 | 2.2× HP / 1.5× 伤(已实现) | 保底 rare+ |
| **领主** | 守卫型小 Boss,被精英营地护卫,**不给门** | 5-8× 精英 | 保底 rare+,大概率 set/unique,掉材料 |
| **Boss** | 最终,死亡位生成门,通关判定 | 现有主题 Boss 体系 | 专属 set / unique |

**各图分布**:

- **普通**:主线白怪/增强填充;分支尽头 = 精英营地或宝藏密室;中程 1 个领主卡主线;右端 Boss。
- **高级**:通道白怪/增强;**四角领主各带一个精英护卫群**;中央最终 Boss。
- **挑战**:四方向区 = 白怪→增强→精英→领主;区尽头元素 Boss;全清后中央最终 Boss。

## 5. 营地三型(随机混合)

按难度与深度随机抽取,丰富营地形态:

- **a. 光环营地**:1 精英 + 5~7 白怪,精英光环强化周围白怪(攻速/移速/减伤);**先杀精英 → 小怪变弱**。
- **b. 精英抱团**:2~3 精英 + 白怪,无光环,靠数量压。
- **c. 双核营地**:精英 + 专职光环者(不攻击、只 buff,死亡后光环消失)+ 白怪;拆解优先级最有层次。

## 6. 机制扩展包(全量上)

> 原则:**每个新机制必须有玩家可读、可接的反制点**(预警 / 翻滚 / 换目标),否则只是堆数值。

### 6.1 包1 · 移动 AI(配给领主/精英)

| ID | 行为 | 反制点 |
|---|---|---|
| `strafe` | 侧移放风筝,远程怪绕圈拉距离 | 预判走位 / 冲刺切入 |
| `leap` | 蓄力扑击,落点预警圈 | 翻滚躲 |
| `burrow` | 遁地移动 + 出地袭击(遁地无敌,可看到土痕) | 看土痕预判 |
| `flee` | 残血逃跑,可拉出连锁仇恨 | 追击决策 / 放走 |

### 6.2 包2 · 怪物机制(配给增强/精英/领主)

| ID | 机制 | 反制点 |
|---|---|---|
| 光环×5 | 狂暴(攻速)/ 加速(移速)/ 石肤(减伤)/ 回复(回血)/ 元素(攻击附伤)——**增强层主食** | 先拆光环来源 |
| `shield` | 护盾周期,打碎后虚弱窗口 | 输出窗口 = 决策点 |
| `explode` | 贴脸自爆 | 翻滚 / 拉开 |
| `thorns` | 近战反伤 | 切技能 / 换目标 |
| `curse` | 命中 debuff(减速 / 禁翻滚短窗) | 药水 / 翻滚清除 |
| `death_trigger` | 死亡触发:爆裂 / 分裂小怪 / 留毒池,三选一 | 处理残余 / 走位 |

### 6.3 包3 · Boss 技能(配给元素 Boss / 最终 Boss)

| ID | 技能 | 反制点 |
|---|---|---|
| `spiral` | 螺旋弹幕(越转越密) | 内圈贴脸 / 外圈躲 |
| `laser` | 激光扫射(方向预警条) | 预警条走位 |
| `nova` | 全向爆发(新星弹幕) | 中距离最优解 |
| `spawn_elites` | 召唤精英(非小怪) | 优先处理召唤物 |
| `teleport` | 阶段瞬移(50% 血换位) | 打破站位,重新定位 |
| `arena_mech` | 场地机制(落石/毒区/尖刺,配合弹幕) | 场地走位 |
| `enrage` | 狂暴(低血攻速+) | 爆发窗口 / 风筝 |

### 6.4 挂载规则

- **增强** = 光环 ×1
- **精英** = 机制 ×1(shield/explode/thorns/curse/death_trigger 随机)
- **领主** = 移动 AI ×1 + 机制 ×1 + bossSkill 三选一(summon/ring/charge 复用)
- **Boss** = 新技能池 2 技能组合(每 Boss 不同)
