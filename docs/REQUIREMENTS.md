# Voidbound 需求规格说明书

> 版本：v1.0  
> 日期：2026-08-08  
> 状态：已批准

---

## 1. 项目概述

### 1.1 项目名称
**Voidbound**（虚空之缚）

### 1.2 项目类型
2D 俯视肉鸽 ARPG（Action Role Playing Game）

### 1.3 项目定位
- 单局时长 30-60 分钟
- 单人游戏（后续扩展多人）
- 像素复古美术风格
- 跨平台：Windows / macOS / Linux

### 1.4 项目愿景
做一款让玩家在 30 分钟内就能体验到"刷装 + build 成长 + 肉鸽变异"的快节奏 ARPG。

## 2. 功能需求

### 2.1 角色系统（F-RPG）

#### F-RPG-001：6 个职业
- **必需**：野蛮人、圣骑士、法师、死灵法师、游侠、刺客
- 每个职业独立属性主属性、专属技能树、专属装备类型

#### F-RPG-002：6 项基础属性
- 力量 / 敏捷 / 体力 / 智力 / 信仰 / 魅力
- 升级时按职业权重自动加点 + 自由加点（每级 5 点）

#### F-RPG-003：技能树
- 每个职业至少 5 个主动技能 + 10 个被动技能
- 每个技能最多升至 20 级
- 技能 10 级后解锁"肉鸽符文变异"

### 2.2 战斗系统（F-CBT）

#### F-CBT-001：基础操作
- WASD 八方向移动
- 鼠标左键：主技能 / 拾取
- 鼠标右键：副技能 / 强制移动
- QWER：4 个技能槽
- 空格：翻滚（短距位移 + 短暂无敌）

#### F-CBT-002：药水系统
- 1-4 数字键对应 4 格药水栏
- 药水类型：HP / MP / 抗性 / 解控

#### F-CBT-003：伤害公式
- 包含基础伤害、属性加成、武器加成、暴击、抗性、易伤、技能加成

#### F-CBT-004：元素系统
- 6 系元素：火 / 冰 / 电 / 毒 / 暗 / 神圣
- 每系抗性上限 75%

#### F-CBT-005：特殊机制
- 击退、击飞、减速、定身
- DOT（持续伤害）：燃烧 / 中毒 / 流血
- Buff / Debuff 系统

### 2.3 怪物系统（F-MOB）

#### F-MOB-001：30+ 种怪物
- 分布在 4 个生态主题
- 4 个 Boss（每个主题 1 个）

#### F-MOB-002：怪物属性
- 等级 / HP / 护甲 / 攻击 / 攻速 / 移速
- 词条池（随机获取词条）
- AI 行为模式：近战追击 / 远程攻击 / 召唤型 / Boss 阶段变换

#### F-MOB-003：精英与 Boss
- 精英怪物：基础怪物 + 额外词条 + 视觉强化
- Boss：多阶段、特殊技能、阶段转换动画

### 2.4 装备系统（F-ITEM）

#### F-ITEM-001：装备槽位
- 8 个装备槽 + 2 个戒指槽 + 1 个护身符槽

#### F-ITEM-002：5 级稀有度
- 普通（白）/ 魔法（蓝）/ 稀有（黄）/ 套装（绿）/ 传奇（金）

#### F-ITEM-003：词条系统
- 属性词条 / 攻击词条 / 防御词条 / 特殊词条
- 前缀 + 后缀组合

#### F-ITEM-004：套装系统
- 每套装 3-6 件
- 装备件数触发不同套装效果

### 2.5 地图系统（F-MAP）

#### F-MAP-001：4 个地图主题
- 暗黑森林（Lv 1-15）/ 灼热沙漠（Lv 15-30）/ 冰冻废墟（Lv 30-50）/ 虚空深渊（Lv 50+）

#### F-MAP-002：WFC 随机生成
- 每次生成不同但保证连通性
- 80×80 tile 网格
- 房间类型：小怪房 / 精英房 / Boss 房 / 商店 / 宝箱房 / 休息点

#### F-MAP-003：视觉差异
- 每个主题独立 tile 集 / 调色板 / 环境粒子

### 2.6 城镇系统（F-TOWN）

#### F-TOWN-001：3 个永久城镇
- 新手镇（默认解锁）
- 商业城（通关森林后解锁）
- 圣城（通关沙漠+冰冻后解锁）

#### F-TOWN-002：城镇设施
- 商店（4 种）/ 训练师 / 神秘商人 / 装备重铸师 / 符文锻造师 / 仓库 / 难度选择

### 2.7 技能变异系统（F-RUNE）

#### F-RUNE-001：符文变异触发
- 技能达到 10 级后，每次升级 30% 概率触发
- 从 3 个随机符文选项中选择 1 个
- 永久改变技能效果

#### F-RUNE-002：变异类型
- 元素转换（火→冰/电/暗）
- 形态变化（直线→弹射/穿透）
- 机制增强（多目标 / DOT / 控制）

### 2.8 UI 系统（F-UI）

#### F-UI-001：HUD
- HP/MP 条 / 等级 / 经验条 / 小地图 / 任务 / 技能栏 / 药水栏 / 怪物血条

#### F-UI-002：界面
- 角色面板 / 背包（40 格）/ 商店 / 城镇地图 / 结算 / 主菜单

### 2.9 存档系统（F-SAVE）

#### F-SAVE-001：3 层存档
- 角色存档：职业 / 等级 / 装备 / 技能 / 永久天赋
- 永久进度：解锁的城镇 / 训练师 / 难度
- 本次运行：当前地图 / HP / 技能冷却 / 背包（死亡丢失）

#### F-SAVE-002：存档位置
- `%APPDATA%/voidbound/saves/`

### 2.10 粒子特效（F-FX）

#### F-FX-001：粒子类型
- 弹道子弹 / 命中粒子 / 环境粒子 / Buff 光环 / Boss 阶段特效

#### F-FX-002：性能要求
- 同时支持 5000+ 粒子保持 60 FPS
- Texture Atlas + Instanced Rendering

## 3. 非功能需求

### 3.1 性能需求（NFR-PERF）

| 指标 | 目标 |
|------|------|
| 帧率 | 60 FPS（4K 分辨率） |
| 粒子数 | 5000 粒子 60 FPS |
| 加载时间 | 启动 < 3 秒，进入地图 < 2 秒 |
| 包体积 | < 100 MB（Tauri 优势） |
| 内存占用 | < 1 GB |

### 3.2 可用性需求（NFR-USE）

- **操作响应**：按键输入 < 16ms 响应
- **新手引导**：前 5 分钟学会基础操作
- **存档自动**：每 30 秒自动保存

### 3.3 可维护性需求（NFR-MAINT）

- **代码组织**：模块化，遵循 Rust + TypeScript 最佳实践
- **注释**：核心算法必须有文档注释
- **测试**：核心战斗逻辑 100% 单元测试覆盖

### 3.4 可扩展性需求（NFR-EXT）

- **新增职业**：数据驱动，不改代码
- **新增怪物**：JSON 配置 + 像素图
- **新增地图主题**：独立配置目录
- **新增技能**：技能系统模块化

### 3.5 跨平台需求（NFR-PLAT）

- **Windows**：Windows 10/11（x64）
- **macOS**：macOS 12+（Intel / Apple Silicon）
- **Linux**：Ubuntu 22.04+（主流发行版）

## 4. 约束条件

### 4.1 技术约束

- **强制使用 Tauri 2.x + Rust + WebGL2**
- 不引入 React / Vue / Three.js 等重型框架
- WebGL2 必须支持（不支持 WebGL1）

### 4.2 美术约束

- **像素风**：32×32 主体精灵，16×16 小怪
- **图集**：单图集 < 4096×4096
- **调色板**：每个主题独立调色板

### 4.3 内容约束

- 第一版只做单局单人，不实现联机
- 第一版不做 PvP
- 第一版不做 mod 支持

### 4.4 时间约束

- MVP：2 周
- 完整版本：7 周内可玩

## 6. 风险与缓解

| 风险 | 等级 | 缓解策略 |
|------|------|----------|
| WFC 实现复杂 | 高 | 用 `fast-wfc` crate，先用预制房间验证 |
| 性能瓶颈 | 中 | 早做基准测试（5000 粒子 60FPS 合格线） |
| 内容设计工作量大 | 中 | 用提示词模板批量生成 LLM 内容 |
| 像素图集美术量大 | 中 | 先用程序化占位图，后期替换美术 |
| Tauri 学习曲线 | 低 | 第一周专注框架熟悉 |

## 8. 术语表

| 术语 | 解释 |
|------|------|
| **肉鸽 (Roguelite)** | 死亡会丢失当前进度但保留部分永久进度的游戏类型 |
| **WFC (Wave Function Collapse)** | 基于约束的随机地图生成算法 |
| **DOT (Damage Over Time)** | 持续伤害（如燃烧、中毒） |
| **Build** | 玩家的技能 + 装备组合 |
| **词条 (Affix)** | 装备上的属性加成 |
| **稀有度 (Rarity)** | 装备品质分级（普通/魔法/稀有/套装/传奇）|
| **符文变异 (Rune Mutation)** | 技能达到 10 级后随机改变技能效果 |
